# Plain English

Write for a tired reader who is not a native English speaker. Each sentence must survive one read.

### Section 1: Words

| Rule | Instruction |
|---|---|
| 1.1 | Use one word for one meaning. |
| 1.2 | You can use domain verbs as technical verbs ("deploy", "compile", "merge"). |
| 1.3 | Do not use technical verbs as nouns. |

**Before:** You can webhook the event, then do a deploy.
**After:** Send the event to the webhook. Then deploy the service.

### Section 2: Sentences

Keep procedural sentences to 20 words or fewer.
