# Global rules (all projects)

## Language

**Code is English only. No exceptions.**
Source comments, identifiers, test names, log strings, commit messages, PR bodies, and
every code snippet inside a design or architecture write-up are written in English.
Hebrew (or any other language) belongs in the chat with the founder, never inside a
code block or a file in a repository. Before sending a message that contains a code
block, check the block for non-ASCII letters.
